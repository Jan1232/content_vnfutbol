# Предложка MAX

Отдельный бот: человек открывает **уникальную** ссылку канала, присылает текст или медиа — бот пересылает это владельцу канала.

Обычная ссылка на бота не принимает предложения.

## Как это работает

1. Владелец добавляет бота **администратором** в канал.
2. Бот пишет владельцу в личку уникальную ссылку вида  
   `https://max.ru/<бот>?start=<хвост>`.
3. Автор переходит по этой ссылке и отправляет материал.
4. Владелец получает пересылку в личку.

Повторно получить ссылку: `/url`.  
Если каналов несколько — бот сначала предложит выбрать канал.

Команды владельца:

- `/setting` — лимит сообщений в час от одного человека и максимальная длина текста (0 — без ограничения).
- `/ban` — список забаненных, разбан по кнопке.

В каждом предложении есть ссылка на отправителя (`max://user/...`) и кнопка «Забанить».

## Запуск

В `.env`:

```
PREDLOZKA_BOT_TOKEN=...
MAX_API_BASE=https://platform-api2.max.ru
```

```bash
PYTHONPATH=/var/max-repost /var/max-repost/.venv/bin/python -m predlozka
```

или через systemd-сервис `max-repost-predlozka`.
